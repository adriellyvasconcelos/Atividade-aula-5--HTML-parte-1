# Atividade-aula-5--HTML-parte-1
📋 Sobre o projeto

A GameZone Retro é uma loja que busca reviver a nostalgia dos videogames dos anos 80, 90 e 2000.

A página apresenta:

Nome e descrição da loja.
Navegação para a seção de produtos.
Link externo para a Nintendo.
Imagem de um controle de videogame retro.
Lista de consoles clássicos.
Tabela com produtos e preços.
🛠️ Tecnologias utilizadas
HTML5
Tags semânticas básicas.
Links internos e externos.
Imagens.
Listas.
Tabelas.
📁 Estrutura do projeto

🚀 Como executar
Baixe ou clone este repositório.
Abra a pasta do projeto.
Execute o arquivo index.html em um navegador.
Confira a página da GameZone Retro.
🎯 Objetivo acadêmico

Este projeto foi desenvolvido para praticar conceitos fundamentais de HTML, incluindo títulos, parágrafos, links, imagens, listas e tabelas.
